Gimelbrant lab · R package

controlFreq

High-confidence allele-specific analysis of RNA-seq at scale.

Try it

QCC demo → Worked examples with adjustable parameters, in the browser. No install.

Install

remotes::install_github("gimelbrantlab/controlFreq")

Or pull the container:

docker pull sasha/ase

Use

compute_iQCC_for_selected_samples(df = allelic_counts, reps = 1:10, sup_Q = 30)

Overdispersion is estimated from foreign RNA spike-ins or from technical replicates. See the wiki for parameter choices and worked pipelines.
